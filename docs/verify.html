AGENT 01 · CREWAI

🛡️ The Verification
Analyst

First in the crew. It reads every structured incident and answers one question: should anyone act on this? Duplicates merge. Rumours die here.

Role: Verification AnalystGoal: trust before dispatchTools: credibility_score · detect_language

WHAT IT DOESThree jobs, one pass

🧬

Deduplication across languages

An Arabic call and an English tweet about the same trapped family become Merged Incident 1, with both sources attached. One rescue, not two.

⚖️

Corroboration plus a credibility tool

Every incident gets a rule-based 0-100 credibility_score with its reasons, and detect_language keeps the Arabic and English streams honest. Two independent reports earns VERIFIED; a single source stays UNVERIFIED.

🧨

Rumour detection

Extreme casualty claims, no site details, no second source: the "dam collapsed, thousands dead" post gets labelled RUMOUR, the label that stops a panic deployment.
