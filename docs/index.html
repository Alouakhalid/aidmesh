Built with

LangChain

Structured intake with Pydantic schema. Arabic and English to clean incident objects.

CrewAI

Verifier, Triage Lead, Dispatcher and Communicator agents in a sequential process.

Groq

gpt-oss-120b on Groq for very low latency inference.

Three.js

The 3D mesh behind this page. Nodes are agents and incidents.

Honest limits: it assists humans, it does not replace dispatchers. In our run the crew ranked the rumour low but still proposed a recon, which a human should veto. Verification labels are the main safety feature.
