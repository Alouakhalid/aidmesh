03 // Why it is differentBuilt for the worst day, not the demo day

Multilingual by default

A panicked voice note in Egyptian Arabic and a tweet in English about the same flood become one incident, not two dispatches.

Rumour firewall

A viral "dam collapsed, thousands dead" post gets flagged as a rumour with a public correction, instead of triggering panic deployment.

Safety-first dispatch

Every recommendation names the hazard to check before moving: live wires, currents, fuel, unstable structures.

Honest by design

Every incident carries VERIFIED, UNVERIFIED or RUMOUR. Humans keep the veto. AidMesh assists dispatchers, it does not replace them.

04 // Agent toolsThese agents do not just chat

The crew calls five real tools: a rule-based credibility scorer, language detection, OpenStreetMap geocoding, Open-Meteo flood-risk weather, and a nearest-resource lookup. The LLM decides; the tools know.
